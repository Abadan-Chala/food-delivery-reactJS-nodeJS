# HuFood Order

Welcome to the HuFood Order repository! This project is a food ordering website developed using the MERN stack (MongoDB, Express, React, Node.js).

## Features

- **User Authentication**: Secure login and registration system.
- **Menu Management**: Browse and manage food items.
- **Order Processing**: Place and track orders in real-time.
- **Admin Dashboard**: Manage users, orders, and menu items.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## Technologies Used

- **Frontend**: React
- **Backend**: Node.js, Express
- **Database**: MongoDB

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/hufood-order.git
    ```
2. Navigate to the project directory:
    ```sh
    cd hufood-order
    ```
3. Install dependencies for both frontend and backend:
    ```sh
    npm install
    cd frontend
    npm install
    ```

### Running the Application

1. Start the backend server:
    ```sh
    npm run server
    ```
2. Start the frontend development server:
    ```sh
    cd frontend
    npm start
    ```
